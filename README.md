# Эмулятор оболочки ОС

Учебный проект по дисциплине «Конфигурационное управление».
Вариант №10. Этап 2 — Конфигурация.

## Описание

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом на Java (Swing).

Реализовано:
- окно с полем ввода и областью вывода;
- заголовок вида `Эмулятор - [username@hostname]`;
- парсер команд и аргументов по пробелам;
- подстановка переменных `$HOME` и `$USER`;
- команды-заглушки `ls`, `cd`;
- команда `exit`;
- обработка неизвестных команд;
- параметры командной строки `--vfs` и `--script`;
- отладочный вывод параметров при запуске;
- выполнение стартового скрипта с пропуском ошибок.

## Параметры командной строки

- `--vfs <путь>` — путь к физическому расположению VFS.
- `--script <путь>` — путь к стартовому скрипту.

Оба параметра необязательные.

## Требования

- JDK 17 или выше.
- Windows — для готовых `.bat`-скриптов.

Скрипты `.bat` сами находят JDK: проверяют `JAVA_HOME`, папку `.jdks` от IntelliJ и стандартные пути установки.

## Сборка и запуск

### Автоматически (Windows)

Запустить двойным кликом один из файлов:

- `run.bat` — с `--vfs` и `--script`;
- `run_vfs_only.bat` — только с `--vfs`;
- `run_script_only.bat` — только с `--script`.

### Вручную

```bash
mkdir out
javac -encoding UTF-8 -d out src/ru/miem/shell/Main.java
java -cp out ru.miem.shell.Main --vfs "./vfs_data" --script "./startup.txt"
```

## Команды

| Ввод | Вывод |
|---|---|
| `ls` | `ls` |
| `cd /tmp` | `cd /tmp` |
| `pwd` | `Unknown command: pwd` |
| `ls $HOME` | `ls C:\Users\<имя>` |
| `exit` | закрытие программы |

`$HOME` и `$USER` подставляются автоматически перед выполнением.

## Пример работы

Отладочный вывод при запуске:

```
=== Отладочный вывод параметров ===
Путь к VFS: ./vfs_data
Путь к скрипту: ./startup.txt
===================================
```

Выполнение стартового скрипта:

```
--- Выполнение стартового скрипта ---
VFS> ls
ls
VFS> cd /tmp
cd /tmp
VFS> invalid_command
Unknown command: invalid_command
VFS> ls C:\Users\Aleksandra
ls C:\Users\Aleksandra
--- Скрипт завершен ---
```
